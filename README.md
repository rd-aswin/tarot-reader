# 🌌 The Digital Sanctuary: Contemplative Tarot & Introspective Archetypes

A modern, accessible, zero-budget web platform that translates traditional tarot rituals into a peaceful, reflective digital sanctuary. Built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and native browser APIs.

## 🕯️ Platform Highlights

* **Liminal Design ("The Digital Sanctuary")**: 60%+ negative space, dark nocturnal canvas (`#0B0B0E`), and zero intrusive SaaS popups, badges, or neon buttons.
* **Hardware-Accelerated 3D Physics**: Fluid, hardware-accelerated 3D card dealing, fanning, and flipping with upright/reversed support.
* **Native Web Audio API Soundscape**: Zero external audio downloads. Procedurally synthesizes Tibetan singing bowl strikes (432Hz / 528Hz) and card friction sounds in real-time.
* **Cryptographic Randomness Engine**: Unbiased Fisher-Yates shuffle powered by `crypto.getRandomValues()`.
* **Zero-Knowledge Privacy Vault**: Private journal reflections and reading history are stored client-side via browser IndexedDB (Dexie.js). Intimate thoughts never touch a remote server.
* **Full Legal Compliance & Safety**: Integrated 18+ age checkpoint, entertainment & self-reflection disclaimers, and an automated crisis keyword interceptor linking to national support helplines (988 Lifeline).
* **100% Free ($0.00 Budget)**: Operates completely offline as a Progressive Web App (PWA) with zero recurring API costs or server dependencies.

## 🚀 Quick Start

### Prerequisites
* Node.js 20+ installed on your machine.

### Installation & Local Run

```bash
# Clone repository
git clone https://github.com/rd-aswin/tarot-reader.git
cd tarot-reader

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to enter the Digital Sanctuary.
