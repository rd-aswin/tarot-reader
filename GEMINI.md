# Tarot Reader Project Guidelines

When operating within this workspace, enforce the following esoteric platform constraints:

## 1. UI/UX: The "Digital Sanctuary" (Liminal Design)
- **Visual Deceleration:** Use generous negative space (60%+) and low-stimulation dark nocturnal grounds to reduce ocular stress.
- **Avoid SaaS Patterns:** No aggressive notification badges, neon CTAs, bouncing widgets, or high-contrast alert banners.
- **Color Palettes:** Utilize one of the approved dark/accessible palettes (e.g., Hermetic Sanctuary, Astral Veil, Herbalist's Grove) with WCAG 2.1 AA/AAA compliance. Avoid stark white backgrounds unless using the "Ancient Grimoire" parchment theme.
- **Animations:** Implement deliberate, rhythmic pacing (e.g., 3-second centering breath, 3D tactile card dealing with physics). Always respect `prefers-reduced-motion: reduce`.
- **Audio:** No audio autoplay. Web Audio API must require explicit user interaction (e.g., "Begin Ceremony") before transitioning from `suspended` to `running`.

## 2. Legal & Compliance: High-Risk Verticals
- **Entertainment Disclaimer:** Every user-facing reading page or checkout flow MUST include the explicit disclaimer: "For entertainment, educational, and personal self-reflection purposes only. Not a replacement for professional medical, legal, or financial advice."
- **Age Gating:** Must mandate an explicit 18+ age verification checkpoint.
- **The Four Red Lines:** Never generate code or readings that permit:
  1. Medical & Psychiatric diagnosis.
  2. Legal & Judicial advice.
  3. Financial speculation & gambling.
  4. Third-party surveillance (spying).
- **Crisis Intervention:** Implement automated keyword interceptors (e.g., suicide, self harm) that pause the reading flow and display a compassionate Emergency Crisis Resources Banner (e.g., 988 in the US).
- **Payment Compliance:** Frame transactions as "Digital Reflection Software" or "Interactive Digital Guidebooks" rather than "Fortune Telling" or "Psychic Services" to avoid automated bans from Stripe/PayPal/Square.

## 3. Privacy & Data Architecture
- **Zero-Knowledge Storage:** Store sensitive queries and journal reflections client-side via IndexedDB using Web Crypto API.
- **No Commercial Profiling:** Do not monetize private questions or use them for third-party ad targeting.
